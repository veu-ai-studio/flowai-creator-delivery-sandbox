# CTO Executive Coordination Layer

This folder is an executive coordination layer; canonical authority remains docs/CANONICAL_REFERENCE.md, docs/BUILD_PROTOCOL.md, and docs/IMPLEMENTATION_PLAN.md.

The purpose of this folder is to give every active FlowAI window a compact, current briefing layer for technical direction, roster clarity, and CTO-level architecture notes.

## File Index

- `roster.md` - Active window roster and role boundaries.
- `current-directive.md` - Active priorities and standing rules for CB, CD, and CR.
- `forge-run-state-architecture.md` - CTO architecture plan for durable ForgeRunState execution.
- `session-brief.md` - Reserved for end-of-session CTO summaries when produced.

## Use

Every technical window should read this folder at session start after the three canonical governing documents. If this folder conflicts with the canonical documents, the canonical documents win.
